# mlopezmad Web V2.2 – Pulido visual

Versión centrada únicamente en estética y coherencia visual de la web pública.

## Cambios principales

- Home: eliminado el logotipo pequeño superior para evitar duplicar `mlopezmad` sobre la portada.
- Home: ajustado el botón `Ver portfolio` para que tenga menos peso y no pise el bloque de métricas en móvil.
- Home: sustituido el texto de `Selección reciente` por un mensaje más útil y editorial.
- Navegación: unificada la navegación móvil en un único botón `Menú` en páginas interiores.
- Páginas interiores: mantenido `mlopezmad` pequeño en cabecera, con botón `Menú` en el mismo sistema visual.
- Contacto: reorganizado para reducir espacios y mostrar mejor los accesos principales en móvil.
- Sobre mí, Series, Portfolio y galerías: reducidos espacios superiores para que el contenido empiece antes.
- Galerías: el header dinámico generado por `js/gallery.js` usa ahora la misma navegación global.
- Caché: actualizados parámetros de versión en CSS/JS para facilitar ver los cambios al subir a GitHub Pages.

## Compatibilidad

No se modifica Studio, Dashboard, Worker, `collections.json`, `galeria.json` ni la estructura de carpetas. La web sigue leyendo los mismos datos existentes.
